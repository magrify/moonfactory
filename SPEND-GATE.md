# MODAL SPEND GATE — READ FIRST, ABSOLUTE

Set by Jack Magri on 2026-11-16, three times, final form verbatim:
"never do anything that cost money in modal without approval"

## The rule

NOTHING that costs Modal money runs without Jack's explicit approval of that
specific spend, given by Jack himself in chat, naming the job and the cost.

- No exceptions. No inferred approvals. No earlier caps carry over.
- Urgency language ("finish the app", "don't stop", "quit stopping")
  authorizes WORK, never SPENDING.
- A general instruction to complete a project is not spend approval.
- Provider top-ups are Jack's step. Generation runs, funded verification,
  camera proof renders, any GPU call: Jack approves each one first.

## The mechanism

Every brief, cron body, or delegated task touching this platform must contain
the line:

    MODAL SPEND: NONE AUTHORIZED

unless it quotes Jack's in-chat approval of the exact spend (job + cost).
A brief without that line is malformed. When work reaches a step that would
cost Modal money, stop there, list the exact job and estimated cost, and wait
for Jack.

## Why this file exists

On 2026-11-16 Muse wrote a "finish the app" brief that treated Jack's order
to finish as approval for Modal generation spend. Jack corrected it
immediately and ordered the rule fixed at the structure layer. This file,
AGENTS.md, and MEMORY.md all carry it so no future brief can miss it.
